GitHub Pages Deployment Guide

Host this interactive dashboard for free on GitHub Pages

1 Save as `index.html`

Save this complete visual artifact into a file named index.html at the root of your GitHub repository.

2 Push Code to GitHub

git add index.html
git commit -m "Add SharePoint Architecture Dashboard"
git push origin main

3 Enable GitHub Pages

  1. Navigate to your GitHub Repository > Settings.
  2. Click on Pages in the left sidebar under "Code and automation".
  3. Under Build and deployment > Source, choose Deploy from a branch.
  4. Select main branch and folder / (root), then click Save.

Your dashboard will automatically publish live at https://<your-username>.github.io/<repo-name>/ in 1-2 minutes!
